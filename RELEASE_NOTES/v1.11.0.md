# Papercut v1.11.0

## Reading and navigation

- When you import an EPUB, Papercut saves its publisher’s table of contents. Open **Contents** beside **Find** to jump to a chapter or section. Uploaded HTML documents with at least two usable headings also get a Contents panel. Expand or collapse nested sections with the mouse, touch or keyboard. EPUB outlines travel with Library Transfer.
- Choose Sepia for reflowable reader pages, including uploaded HTML and EPUBs. Source Sans 3 and Merriweather join the reader fonts, and the text-size control now goes up to 40 px. The interface uses Inter with fallbacks for each language.
- Settings groups related controls together. PDF reader controls fit narrower screens, and Keyword search puts the All Words and Broader matching choices beside the results selector.

## Library

- Open documents directly from their titles in Gallery or List. On phones, Import and Manage share one row with the view switch, Bookmarks and Saved Audio when space allows. At larger text sizes the controls wrap, keeping the Saved Audio label visible in both left-to-right and right-to-left layouts.
- In Manage, select a folder to move its entire subtree through the destination picker. Filtering the list or using Select All preserves folders you already checked. Confirmed moves apply together, and deletion confirmation accounts for filtered selections.
- Imported audiobooks stay in the library and can be reopened after restarting the desktop app.

## Narration and saved audio

- PDF narration rejoins words split at the end of a printed line and preserves genuine compound hyphens. Highlights and play-from-here still follow the source text. If this changes the passages in an existing PDF audiobook, Papercut prompts you to regenerate it.
- The native speech engine now uses Sherpa ONNX 2.0.1. English Kokoro 7M and Arabic Nabra 7M are smaller, experimental voice choices. Setup recommends Kokoro for English and Kareem for Arabic.
- Completed audiobooks remain playable after the engine upgrade. When an unfinished save uses an incompatible engine revision, Papercut asks before restarting generation and discarding partial audio.

## Distribution and maintenance

- The macOS builds require macOS 15 or later on both Apple Silicon and Intel.
- The localized website groups downloads and installation instructions by platform and shows desktop and Android walkthroughs. The Android store listing has updated English and Arabic screenshots.
- Desktop smoke tests cover search, bookmark restoration, Library reopening, playback controls and opening audiobook bundles in a running app on Linux and Windows.
- Dependency updates include fixes in the HTML sanitizer and the Rust QUIC, cookie and URL dependencies. Android license notices now use verified ONNX Runtime license data.
