# Papercut v1.10.0 - Release Notes

- **Target release:** 1.10.0
- **Release type:** Cross-platform minor feature release

## TL;DR

Papercut v1.10.0 rebuilds Library Transfer around secure pairing and nearby-device
discovery, improves keyword search, and adds an experimental, opt-in conceptual
search that finds related passages without identical wording. Saved audiobooks
can now start from any visible passage or text selection.

This release also preserves EPUB SVG illustrations and cover pages, and polishes
the reader, transfer dialog, and mobile navigation for smaller screens.

The practical highlights are:

- Send or receive selected documents and saved audiobooks between nearby
  Papercut devices with secure 12-symbol pairing codes.
- Discover nearby transfer sessions on Linux, Windows, macOS, iOS, and Android
  14 or later, or enter an address manually.
- Search with explicit **All Words** or **Broader** matching, Arabic-aware
  normalization, and spelling-retry suggestions from your own Library.
- Turn on experimental **Conceptual** search to find related passages in
  imported documents, fully on-device after a one-time model download.
- Play a saved audiobook from the passage you are reading or from selected text.
- Keep EPUB SVG illustrations and cover pages, with clear notices for images
  that cannot be shown.

**Upgrade note:** local-network transfers now use protocol `PCLAN004`, so both
devices need Papercut v1.10.0 or later. Transfer files (`.papercut-library`)
are unchanged and still work with earlier versions.

## Added

### Library Transfer

- **Send and Receive flow.** The dialog starts with Send or Receive. Senders
  choose content first, then connect; receivers go straight to pairing.
- **Secure v4 pairing.** Sessions authenticate with 12-symbol pairing codes
  within a ten-minute pairing window. Codes are formatted automatically as
  they are typed or pasted.
- **Both connection directions.** By default the receiver listens and the sender
  connects. An **Alternative Connection Method** lets the receiver connect
  instead when a firewall blocks incoming connections. Papercut never switches
  direction silently or changes firewall settings.
- **Nearby discovery.** Find nearby sessions through each platform's own
  discovery service. Discovered names are unverified hints; the pairing code
  remains the security check. Android 8–13 and Linux hosts without Avahi keep
  manual and transfer-file options.
- **Clear outcomes.** Papercut reports **Outcome Unknown** when delivery may
  have completed but the receiver's result is unavailable, instead of claiming
  success or offering an automatic resend.
- **Diagnostics.** A **Show Details** panel lists recent transfer activity,
  newest first, and copies a redacted report for troubleshooting. Keys,
  addresses, document contents, and private paths are excluded.

### Search

- **All Words and Broader matching.** All Words requires every unquoted word.
  Broader allows some missing words for longer searches while keeping quoted
  phrases mandatory.
- **Better ranking and evidence.** Title and heading matches rank higher, and
  results show bounded passages with term coverage and source locations.
- **Arabic-aware matching.** Searches ignore tashkeel and tatweel and normalize
  common alef forms without changing the stored text.
- **Spelling retries.** Papercut offers a retry using words from your indexed
  Library and never silently replaces your query.
- **Experimental conceptual search.** Off by default. After you download and
  verify an embedding model in Settings, a **Keyword / Conceptual** switch below
  the search bar finds related passages in imported documents. Model weights
  are downloaded only with your consent, are checksum-verified, and are never
  bundled in the app.

### Audiobooks and reading

- **Play from anywhere.** Start a completed saved audiobook from the first
  visible passage or from selected text. Playback begins at the saved chunk
  containing that location and continues through the book.
- **Follow or browse.** Scrolling, Find, bookmarks, and links pause automatic
  following without changing playback. **Return to Audio** jumps back to the
  current passage.
- **Exact Resume.** Resume still continues from the paused audio position.

### EPUB images

- Preserve external and inline SVG illustrations, including SVG-wrapped cover
  pages.
- Report images that cannot be kept as import warnings and reader placeholders
  instead of dropping them silently.

## Changed

- **Reader settings (Aa)** open in a panel that stays put while the document
  scrolls, so font, size, and spacing changes can be judged across the page.
  Escape or a tap outside closes it.
- **Bookmark menu** now reads **Jump to Bookmark**, **Update to Current
  Position**, and **Remove Bookmark**, and stays above the playback controls.
- **Mobile tab bar** is a floating capsule with a filled pill for the active tab.
- **Narrow screens:** the reader header keeps its controls on one row on typical
  phones, with icon-only Back and Find buttons. Queue card actions line up at
  narrow widths.
- **Dialogs** stop the page behind them from scrolling.
- **Transfer dialog** is more compact: the network refresh button sits beside the
  network list, and the disabled **Receive Library** button explains what is
  missing.
- **Dark mode** dividers and notifications use softer, tonal styling.

## Fixed

- Completed audiobooks could be missing from the Audiobooks list until the app
  refreshed.
- PDF passage matching could reject valid saved chunks spanning several
  paragraphs.
- Refreshing networks no longer collapses the transfer dialog's Network
  Settings section.
- The PDF Find and bookmark targeting around wrapped words now matches the
  rendered PDF text.

## Security and dependency maintenance

- Update ZIP handling for RUSTSEC-2026-0367, RUSTSEC-2026-0368, and
  RUSTSEC-2026-0369.
- Update the Ammonia HTML sanitizer for RUSTSEC-2026-0373.
- Apply npm and Rust TLS dependency security updates.

## Compatibility And Upgrade Notes

- **Local-network transfer requires v1.10.0 on both devices** (`PCLAN004`).
  Earlier releases use `PCLAN003` and cannot pair with this version.
- Transfer files, saved audiobooks, and `.papercut-audiobook` bundles remain
  compatible. Model files and derived search or playback caches are not
  transferred.
- The upload database migrates automatically to schema 13 when it first opens.
  No re-import or library reset is required.
- Conceptual search builds a separate, derived index. Changing the embedding
  model or precision requires rebuilding that index; keyword search is not
  affected.

## Known Limitations

- Conceptual search is experimental. Larger models need more memory and
  processing time, and results are related passages, not guaranteed answers.
- Nearby discovery depends on platform services, permissions, and network
  policy. Manual addressing cannot bypass a blocked listener; use the
  alternative connection method or a transfer file.
- On iOS 15.0–15.3, the page behind an open dialog can still scroll.
- The first playback on Linux can pause briefly after starting.

## Release Verification

Before tagging `v1.10.0`:

- Run `npm audit --audit-level=high`, `npm run lint`, `npm test`,
  `npm run build`, and `npm run check:i18n`.
- Run `cargo audit --file src-tauri/Cargo.lock --ignore RUSTSEC-2026-0235`
  and the Rust test suites.
- Run CI with `validation_scope: mobile` for the iOS candidate.
- Smoke test an installed build on Linux, Windows, macOS, Android, and iOS.
- Transfer between two v1.10.0 devices in both connection directions, with
  discovery and with a manual address, and through a transfer file.
- Download, verify, enable, and disable a conceptual search model on a fresh
  profile.
- Play a saved audiobook from a visible passage and from a selection on desktop
  and Android.
