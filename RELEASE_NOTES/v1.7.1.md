# Papercut v1.7.1 - Release Notes

- **Target release:** 1.7.1

Papercut v1.7.1 is a Linux desktop patch release for the SILMA Arabic TTS
release path introduced in v1.7.0.

## Fixed

- **SILMA appears in packaged Linux builds.** The old development opt-in flag was
  removed, so Linux x64 users can select `SILMA Arabic TTS` from Audio Setup
  from a normal installed app launch.

## Changed

- **Runtime metadata points at v1.7.1 assets.** The SILMA runtime-pack part URLs
  now target the v1.7.1 GitHub Release assets while keeping the same pinned
  archive byte size and SHA-256 verification.

## Verification

- Install the v1.7.1 Linux `.deb` from a clean Papercut app-data/cache state.
- Confirm `SILMA Arabic TTS` appears under Arabic without any env vars.
- Install SILMA from Audio Setup, probe the sidecar, and generate a short Arabic
  audiobook.
