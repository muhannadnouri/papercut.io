# Papercut v1.5.1 - Release Notes

- **Target release:** 1.5.1
- **Release branch:** `branch-release-v1.5.1`

Papercut v1.5.1 is a focused stability release for iOS/WebKit and mobile reader workflows. It keeps the v1.5.0 feature set intact while reducing input zoom, reader crashes, and exact-search friction on Apple keyboards.

## Fixes

- **Reduced iOS input zoom.** Mobile form controls now use iOS-safe text sizing so focusing document filters, Find, dialogs, and reader settings should no longer zoom the page unexpectedly.
- **Improved Find stability on large documents.** In-page Find keeps live-search behavior but debounces full-document highlighting to reduce DOM churn while typing through large EPUB/HTML documents.
- **Reduced iOS/WebKit reader crash paths.** Reader navigation uses instant scrolling on iOS/WebKit and avoids extra search-target DOM mutation there, which reduces black/white-screen failures after jumping deep into large EPUBs.
- **Exact phrase search accepts Apple smart quotes.** Queries typed with curly double quotes from the iOS keyboard are normalized before exact phrase parsing.
- **Consistent dialog typography.** App dialogs now use the shared app font stack so iOS dialogs match the rest of the interface more closely.
- **Fixed Find lint regression.** Empty Find queries reset match state from the input handler instead of synchronously inside the debounce effect.

## Notes

- These changes are intentionally conservative for a patch release. The larger long-term performance path for very large books is still to virtualize or chapter-scope reader rendering rather than mutating the full document at once.
- Run the release PR through the normal desktop, Android, iOS, and static-site CI before tagging `v1.5.1`.
