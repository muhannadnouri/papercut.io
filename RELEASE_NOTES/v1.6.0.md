# Papercut v1.6.0 - Release Notes

- **Target release:** 1.6.0
- **Release branch:** `branch-release-v1.6.0`

Papercut v1.6.0 improves imported EPUB search and reading quality, adds explicit reader bookmarks, expands saved-audiobook export with WAV files alongside Papercut bundles, and makes audiobook playback speed a listener preference. It also includes several internal TTS refactors that keep the current behavior intact while making future audio work easier to maintain.

## Added

- **Reader bookmarks.** Readers can save, update, or remove a bookmark from the floating reader controls, then return to that saved position when reopening the document. The bookmark action is paired with the existing Top control and uses short toast feedback.
- **WAV export for saved audiobooks.** Saved audiobooks can now be exported either as a `.papercut-audiobook` bundle for Papercut re-import or as a plain `.wav` file for playback in other audio apps.
- **Audiobook playback speed control.** Saved-audiobook playback now has a tap-to-cycle speed button with listener speeds from `0.5x` through `3x`.
- **Clearer audiobook action feedback.** Audiobook import, export, and delete actions now use blocking progress feedback while the file operation is running, plus dismissible success/error toasts afterward.

## Changed

- **EPUB search indexing is more robust.** Uploaded EPUB search now uses DOM-based section extraction, preserves inline text, handles prose spread across different sections for fuzzy searches, and keeps compound terms such as hyphenated words together where appropriate.
- **Search result language is clearer.** Search mode hints and fuzzy-result cards now better explain broad word search versus quoted exact phrase search, including cases where terms are found in different sections.
- **EPUB reader formatting is cleaner.** Generated EPUB reading HTML now keeps paragraph spacing for div-based prose and avoids treating empty XHTML `pre` blocks as large code-like regions.
- **Saved audiobook metadata is easier to scan.** Saved cards now show user-facing metadata such as model, voice, speed, preprocessing, duration, and size, without lower-level implementation labels.
- **Audio Setup organization is clearer.** Language and model selection are separated in the UI, and Audio Setup labels use the same lightweight visual metadata style as saved audiobook cards.
- **New audiobook generation is fixed at 1x.** The Generated Speed control remains visible but disabled; users now change listening speed from the player controls instead of generating separate slowed-down or sped-up WAV files.
- **Audiobook export menu copy is format-focused.** Bundle and WAV export options now use consistent “Export as” language with inline file extension pills.

## Fixed

- **iOS search-result jumps.** Search result navigation on iOS avoids DOM mutation and uses the reader highlight path, restoring jump-to-match behavior without increasing WebKit memory pressure.
- **iOS release metadata.** The committed generated Apple project now carries the v1.6.0 marketing/build version so IPA metadata matches the app release.
- **EPUB exact and fuzzy search misses.** Several EPUB cases that Find could locate but global search missed are now indexed and matched correctly.
- **Fuzzy fallback ranking.** Cross-section fallback candidates are ranked before result limiting, so fallback matches are not selected merely by document ID order.
- **Audiobook action UI edge cases.** Export menus close when clicking elsewhere, actions are disabled while another file operation is running, and busy overlays no longer expose unrelated controls during import/export/delete operations.
- **Reader floating controls during playback.** Bookmark and Top controls remain visible during audiobook playback on wider screens instead of being covered by the floating audio player.
- **Queued audiobook removal safety.** Removing a queued or paused audiobook save job now requires confirmation, matching the saved-audiobook delete flow and reducing accidental loss of resumable work.
- **Audiobook panel polish.** Toast close icons, busy overlays, panel borders, export menu clipping, and mobile/wide layout details were tightened.

## Refactoring

- **Native TTS text normalization split out of synthesis.** Text cleanup now lives outside the synthesis module so model/language-specific pronunciation behavior is easier to reason about.
- **Audiobook save internals split by responsibility.** Manifest writing and pruning logic were separated from the main save flow.
- **Bundle export internals split from WAV stitching.** `.papercut-audiobook` export and shared WAV stitching are now separated so bundle export and plain WAV export can evolve independently.

## Compatibility and Upgrade Notes

- Existing saved audiobooks and `.papercut-audiobook` bundles remain compatible.
- New audiobook saves generate audio at `1x`; existing saved or imported audiobooks keep their stored generated-speed metadata for compatibility.
- Playback speed is a listening preference only. It does not change cache keys, saved-audiobook availability, exports, or imported bundle metadata.
- WAV export is additive and does not change the existing Papercut bundle format.
- Reader bookmarks are local app state and do not alter stored document HTML, EPUB-generated reading HTML, search indexes, or saved audiobook metadata.
- EPUB search/reader improvements affect newly imported or reprocessed uploaded EPUB content. If an older imported EPUB still shows stale search behavior, delete and re-import that document.
