# Papercut v1.7.3 - Release Notes

- **Target release:** 1.7.3
- **Release type:** Linux desktop patch

Papercut v1.7.3 refreshes the optional SILMA Arabic TTS Linux runtime pack and
keeps the public release on the passing CPU runtime path.

## Changed

- **Fresh SILMA CPU runtime metadata.** The checked runtime manifest now points
  at the v1.7.3 split Linux x64 CPU runtime assets and pins their byte sizes and
  SHA-256 hash.
- **CUDA runtime deferred.** The experimental CUDA runtime remains disabled
  until its source-preserving runtime can pass packaged import checks with a
  loadable CUDA runtime.

## Validation

- Run the SILMA Runtime Pack workflow for `v1.7.3` and confirm the Linux x64 CPU
  runtime job passes.
- Attach both split runtime parts to the v1.7.3 GitHub Release.
- Install the Linux `.deb` or AppImage from a clean Papercut app-data/cache
  state, install SILMA from Audio Setup, probe the sidecar, and save a short
  Arabic audiobook.
