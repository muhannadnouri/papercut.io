# Papercut v1.7.0 - Release Notes

- **Target release:** 1.7.0
- **Release branch:** `branch-release-v1.7.0`

Papercut v1.7.0 adds the first production path for SILMA Arabic TTS on Linux
x64 desktop, improves audiobook export and AI-audio disclosure, and polishes
reader playback/highlighting behavior. SILMA ships as an optional runtime
download instead of being bundled into the base app installer.

## Added

- **SILMA Arabic TTS for Linux x64 desktop.** Linux users can select SILMA as an
  Arabic TTS backend, install its runtime/model files on demand, probe the
  sidecar from diagnostics, and generate saved audiobooks through the existing
  audiobook pipeline.
- **Optional SILMA runtime packs.** The large Python/PyTorch SILMA runtime is
  built separately in CI and downloaded only when users enable SILMA.
- **SILMA CPU tuning controls.** Audio Setup exposes SILMA quality/NFE options
  and honors the existing thread-count control for PyTorch CPU inference.
- **AI audio export disclosure.** Exporting any generated audiobook now confirms
  that the audio is AI-generated. SILMA exports also warn about reference voice
  permissions.
- **Approximate word highlighting.** Audiobook playback can highlight the
  current word approximately while a saved audiobook is playing.
- **Reader font selector.** Reader settings now use a reusable select control
  for font choices.

## Changed

- **Audiobook export menus are clearer.** Bundle and WAV exports now describe
  the format first, with AI-audio guidance shown once as supporting text.
- **Saved audiobook metadata identifies generated audio.** Saved cards now make
  generated audio visible and identify reference-voice output where relevant.
- **SILMA is Linux-only for now.** Windows, macOS, Android, and iOS hide SILMA
  until upstream Python dependencies can be packaged reliably there.
- **Development watcher load is reduced.** Vite and editor watcher excludes now
  avoid generated Android output, local TTS runtimes, caches, and large local
  test fixtures.
- **Public docs and site copy are clearer about generated audio.** The README,
  site FAQ, and policy docs now avoid broad ownership claims and remind users to
  label shared generated audio.

## Fixed

- **SILMA install readiness.** The UI no longer treats SILMA as installed unless
  both the model files and runtime pack are available.
- **SILMA metadata restoration.** Imported SILMA audiobook bundles restore their
  stored NFE setting when reopened, preserving cache identity.
- **SILMA model-file detection.** Model detection requires `model.pt` and
  `vocab.txt` to coexist in one snapshot directory.
- **SILMA diagnostics.** Diagnostics now report the detected Torch device and
  avoid misleading `unknown` runtime state where possible.
- **SILMA sidecar protocol robustness.** Third-party Python logs are redirected
  away from JSONL stdout so Rust can parse worker responses reliably.
- **Saved SILMA labels.** Saved audiobook cards now show SILMA model metadata
  instead of falling back to Kokoro labels.

## Compatibility and Upgrade Notes

- Existing saved audiobooks and `.papercut-audiobook` bundles remain compatible.
- SILMA does not change the existing `native-save-v4-segmented` cache version.
- SILMA is available only on Linux x64 desktop builds in this release.
- SILMA runtime packs and model files are app data, not installer payloads.
- Public SILMA install uses the checked v1.7.0 Linux runtime-pack part URLs,
  original archive byte size, and SHA-256 in
  `src-tauri/tts/silma-runtime-packs.json`.
- The upstream SILMA sample reference voice remains development-only unless its
  redistribution/default-profile rights are confirmed.
