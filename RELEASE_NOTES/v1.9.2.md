# Papercut v1.9.2 - Release Notes

This patch updates iOS build configuration following App Store Connect warnings.

- Raise the minimum supported iOS version from 14.0 to **15.0**. Users on iOS 14
  must update iOS to install this release.
- Explicitly declare that documents are imported as copies rather than opened
  in place. Papercut continues to import into its own library without editing
  the original file.
- Verify the signed IPA's minimum OS version and document configuration before
  uploading it to App Store Connect.

The Kokoro download repair from v1.9.1 remains included. No library reset or
model reinstallation is required.
