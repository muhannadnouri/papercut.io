# Papercut v1.7.4 - Release Notes

- **Target release:** 1.7.4
- **Release type:** Linux desktop patch

Papercut v1.7.4 refreshes the optional SILMA Arabic TTS Linux runtime pack after
the packaged dependency check exposed missing FFmpeg shared libraries.

## Fixed

- **Packaged SILMA runtime can load TorchCodec.** The Linux runtime pack now
  bundles the FFmpeg `libav*`/`libsw*` shared libraries needed by TorchCodec,
  while keeping the base Papercut installer unchanged.
- **Runtime CI rejects incomplete audio stacks.** SILMA runtime-pack CI now runs
  the packaged worker dependency check before producing release artifacts, so
  Torch/TorchCodec/FFmpeg mismatches fail before publishing.

## Verification

- Run the SILMA Runtime Pack workflow for `v1.7.4` and confirm the Linux x64 CPU
  runtime job passes.
- Attach both split runtime parts to the v1.7.4 GitHub Release.
- Confirm `src-tauri/tts/silma-runtime-packs.json` matches the generated v1.7.4
  manifest before tagging the app release.
- Install the Linux `.deb` or AppImage from a clean Papercut app-data/cache
  state, install SILMA from Audio Setup, probe the sidecar, and save a short
  Arabic audiobook.
