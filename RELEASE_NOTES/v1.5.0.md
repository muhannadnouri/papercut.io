# Papercut v1.5.0 - Release Notes

- **Target release:** 1.5.0
- **Release branch:** `branch-release-v1.5.0`
- **Primary change:** Search, reader, audiobook, and landing page quality-of-life release.

Papercut v1.5.0 focuses on making the offline library workflow easier to understand and harder to disrupt: clearer search results, better reader/list navigation, safer audiobook actions, stronger light/dark contrast, a redesigned landing page, and a cleaner React UI structure for future maintenance.

## Highlights

- **Clearer search results.** Search summaries now distinguish fuzzy term searches from exact phrase searches, preserve query casing in user-facing labels, respect selected document filters, and show exact phrase occurrence counts where available.
- **Better search snippets.** Exact phrase excerpts decode HTML entities, fuzzy searches can fall back to bounded local excerpts, and search result cards avoid repeating section labels when a useful snippet is available.
- **Search-to-reader improvements.** Opening a search result can jump to the likely matching reader section, and going back from the reader restores the previous library/search scroll position instead of returning to the top.
- **Safer audiobook actions.** Risky delete/save flows now use confirmation dialogs, empty audiobook save attempts are handled, and local audiobook metadata writes are best effort so storage failures do not crash native save/import/delete flows.
- **External links open correctly.** Reader external links now open through the operating system browser in Tauri builds, with a browser fallback outside Tauri.
- **Improved app contrast and mobile polish.** Light/dark theme contrast, focus states, reader toolbar controls, library rows, audiobook controls, and mobile touch targets were refined.
- **Cleaner app structure.** The app shell was split into focused tab/header components, large CSS was moved into component-owned stylesheets, and document viewer/uploaded library state moved into dedicated hooks.
- **Redesigned static website.** The landing page now has clearer product positioning, improved download flows, dark/light theme support, a Netlify contact form, release/resource links, and updated starter documents.
- **CI and release housekeeping.** Netlify deploys are skipped when site files are unchanged, generated Tauri files are ignored by Vite dev watch, and Tauri opener package versions are pinned to the existing Tauri 2.10.x stack.

## Compatibility

No data migration is expected. Existing imported documents, saved audiobook metadata, downloaded models, and user settings should continue to work. If local browser/WebView storage is unavailable or full, some audiobook metadata writes may be skipped instead of crashing the app; native files remain managed separately.
