# Papercut v1.8.0 - Release Notes

- **Target release:** 1.8.0
- **Release type:** Cross-platform minor feature release

## TL;DR

Papercut v1.8.0 is the largest feature release since v1.7.4. It adds offline
support for text-native PDFs, secure local library transfer, multi-file and
folder imports, a cover-based Library gallery, multilingual and right-to-left
UI support, expanded Kokoro voices, and more capable saved-audiobook workflows.
Search, bookmarks, document management, responsive layouts, and interaction
feedback have also received broad correctness and usability work.

The practical highlights are:

- Import, search, read, bookmark, narrate, and transfer text-native PDFs.
- Move a library directly between Papercut devices without an account or cloud.
- Import and manage many documents at once, including desktop folder imports.
- Browse EPUB and PDF covers in the default Library gallery or switch to List.
- Use Papercut in English, Arabic, and six experimental additional UI locales.
- See and open every saved audiobook for a document regardless of Audio Setup.

This remains a compatible `1.x` release rather than `2.0`: it expands the
product substantially without intentionally breaking Papercut's public data
formats or requiring users to rebuild their libraries.

## Added

### PDF reading, search, and audio

- **Text-native PDF import.** PDFs with embedded text can be imported into the
  same offline library and full-text index used by HTML and EPUB documents.
- **Responsive PDF viewer.** The reader includes bounded page rendering,
  previous/next page controls, editable page and zoom values, fit-width and
  fit-page modes, fullscreen, optional two-page spreads, and responsive desktop
  and mobile layouts.
- **PDF Find and search navigation.** In-document Find and Library search
  results open the relevant indexed page and highlight matches without parsing
  the entire document again on every navigation.
- **PDF narration.** Extracted page text is reconstructed into logical prose for
  TTS, preserving reading order and reducing abrupt chunk boundaries.
- **PDF TTS highlighting.** Saved-audiobook playback highlights the active
  source span in rendered PDF pages.
- **Semantic PDF bookmarks.** PDF bookmarks store page-relative coordinates so
  restoration remains stable across zoom and viewport changes.
- **PDF covers.** Gallery thumbnails are generated from the first page using
  bounded image dimensions and persisted with uploaded-document metadata.
- **Portable PDF audiobooks.** Papercut audiobook bundles can carry their PDF
  source so imported audio remains readable and searchable on another device.

### Library import and organization

- **Multi-file import.** Select up to 500 HTML, EPUB, or PDF files in one import
  operation with progress, cancellation, and per-file success/failure results.
- **Desktop folder import.** Import supported files directly inside one folder;
  subfolders are intentionally skipped.
- **Bulk deletion.** Manage mode can select and delete many documents while
  reporting partial failures instead of hiding successful work.
- **Editable metadata.** Manage mode exposes document details and lets users
  correct uploaded titles without renaming the source file.
- **Gallery view.** The Library now defaults to a responsive Books/Documents
  gallery with retained EPUB covers, generated PDF thumbnails, placeholders,
  and an optional classic List view.
- **Bookmark discovery.** Gallery badges and a quick filter identify documents
  with saved reader bookmarks.
- **Bundled folder hierarchy.** Documents shipped under `public/documents/`
  preserve their directory structure in Library and Search filtering.

### Offline library transfer

- **Nearby transfer.** Send uploaded documents and folders directly between two
  Papercut devices on the same local network using an address and pairing code.
- **Transfer files.** Export or import the same portable library package through
  USB, shared storage, or another user-chosen transport.
- **Selective audiobooks.** Choose individual completed saved audiobooks to add
  to a transfer instead of including the entire audio library.
- **Resumable progress.** Sender and receiver report packaging, transfer,
  validation, document import, search rebuilding, and audiobook restoration.
- **Hardened packages.** Package limits, path validation, source ownership,
  authenticated transport, structured errors, disk-space checks, and atomic
  promotion protect receiving libraries from malformed or partial transfers.

### Languages, voices, and settings

- **Localized UI foundation.** English and Arabic are supported UI locales.
  Simplified Chinese, Spanish, French, Hindi, Italian, and Brazilian Portuguese
  are available as experimental translations pending native-speaker review.
- **Right-to-left layouts.** Arabic includes document direction preservation,
  mirrored application layouts, mixed-direction metadata handling, and correct
  playback/control icon behavior.
- **Multilingual Kokoro.** Papercut exposes supported Mandarin Chinese, Spanish,
  French, Hindi, Italian, and Brazilian Portuguese voices with locale-aware
  synthesis settings and available voice-quality grades.
- **App Settings.** Language, system/light/dark theme, desktop zoom, version
  information, and Library Transfer now live in one settings dialog.
- **Reader appearance controls.** Font, font size, line spacing, reading width,
  and reset controls use responsive, accessible shared selectors.
- **SILMA quality updates.** NFE 32 is the recommended default and NFE 64 is
  available as the highest-quality option. Linux x64 developers can also
  prepare an explicitly validated local NVIDIA CUDA runtime.

### Desktop behavior

- **Single-instance desktop app.** A second Papercut launch focuses the existing
  window instead of opening another process against the same local data.

## Changed

- **Saved Audio is document-wide.** Library filtering and reader controls now
  recognize any saved audiobook for a document, not only audio matching the
  currently selected model, language, voice, preprocessing, or quality setup.
- **Saved versions are selectable.** The reader lists saved audiobook variants,
  restores their recorded setup, and lets the user play the intended version.
- **Saved audiobook list is denser.** Responsive cards/grids retain title,
  model, voice, duration, and storage metadata while consolidating export and
  deletion into an accessible actions menu.
- **Audio Setup is a dialog.** Model and voice configuration no longer expands
  the whole Audiobooks panel. Controls use a compact responsive two-column
  layout with model download/status information next to the selected model.
- **Library management is contextual.** Selection counts, move destinations,
  folder actions, metadata editing, and destructive actions appear only when
  relevant and use larger row targets for touch and keyboard users.
- **Import feedback is persistent but dismissible.** Batch summaries no longer
  remain as unstructured text in the document list.
- **Reader Find is cached and interruptible.** Large HTML and EPUB documents
  reuse their searchable text representation and avoid blocking the interface
  on every keystroke.
- **Reader bookmarks are semantic.** HTML and EPUB bookmarks use text offsets;
  PDFs use page coordinates. This replaces brittle whole-page scroll ratios.
- **Search normalization is more tolerant.** Exact phrases can span inline
  formatting and line breaks, and PDF end-of-line hyphenation can match joined,
  hyphenated, or spaced query forms.
- **HTML import security is stricter.** Imported HTML uses parser-based element,
  attribute, and URL-scheme allowlists before rendering.
- **Native TTS runtime is aligned.** sherpa-onnx 1.13.4 is used across Rust,
  desktop, Android, and iOS preparation paths.
- **Visual hierarchy is consistent.** Shared tonal fills, surface borders,
  radii, selected states, focus indicators, touch feedback, menus, dialogs,
  toasts, diagnostics, and responsive controls now follow one app-wide system
  in light and dark themes.
- **Dark reading palette is calmer.** Reader and application surfaces use more
  deliberate contrast without forcing pure black or bright white everywhere.
- **React responsibilities are smaller.** Reader search, TTS highlighting,
  playback, saved-audio actions, model lifecycle, upload state, and transfer
  behavior were split into focused modules with regression coverage.

## Fixed

- PDF canvases now complete their initial render and resynchronize after layout
  or viewport changes instead of appearing blank until the user changes zoom.
- Deep PDF page jumps no longer pull scrolling back while nearby pages mount.
- PDF bookmarks restore the correct page area and retain their active state as
  zoom changes.
- Two-page PDF spreads pair adjacent pages instead of only increasing vertical
  spacing.
- PDF exact-phrase validation no longer accepts unrelated page text or misses
  common line-wrap hyphenation forms.
- Reader Find now matches text split by bold, italic, links, and other inline
  markup without highlighting an entire surrounding paragraph.
- Large-document Find no longer freezes the UI while typing short prefixes.
- Native background playback uses the document title instead of an internal
  randomized source filename.
- Deleting an uploaded document is blocked while a saved audiobook still
  depends on that source, preventing unplayable orphaned audio.
- Audiobook bundle imports are staged and validated before replacing persistent
  files, reducing partial-import and path-traversal risks.
- Imported-audiobook success is no longer reported as failure when only the
  follow-up document navigation fails.
- Native TTS bridge-load failures use the same stable error normalization as
  command failures.
- Import and deletion operations are serialized so stale refreshes cannot
  overwrite newer Library state.
- Dropdowns and popovers dismiss on outside click or Escape, remain within the
  viewport, and expose appropriate focus and menu semantics.
- Arabic search placeholders, filters, reader settings, Library controls, and
  mixed English technical summaries align correctly in RTL layouts.
- Folder and document rows use their full visible label area as a selection or
  expansion target on touch screens.
- Storage sizes, transfer counts, and status values use locale-aware number
  formatting.

## Compatibility And Upgrade Notes

- Existing uploaded HTML/EPUB documents, saved audiobooks, and
  `.papercut-audiobook` bundles remain supported.
- Uploaded-document schema changes are additive and run automatically when the
  local database opens; users do not need to re-import their library.
- Existing reader bookmarks from v1.7.4 are intentionally not migrated because
  v1.8.0 replaces viewport-dependent scroll ratios with semantic viewer
  locations. New bookmarks are stable across font, zoom, and viewport changes.
- The Gallery is now the default Library view. Users can switch to List at any
  time from the Library toolbar.
- PDF search, exact phrases, Find, and TTS require embedded text. Image-only and
  hybrid-document OCR, camera scanning, and scan-to-book remain future work;
  image-only PDFs can still be rendered when PDF.js supports the source.
- Nearby transfer remains offline and account-free. Both devices must be on the
  same reachable network and keep the transfer screen open.
- SILMA remains available on Linux x64 desktop. Other desktop and mobile builds
  continue to hide it until its sidecar dependencies can be packaged and tested
  reliably on those platforms.
- The checked SILMA CPU runtime still points to the immutable, verified v1.7.4
  release assets; an app version bump does not require republishing identical
  runtime bytes.

## Verification

- Run `npm run lint`, `npm test`, `npm run build`, and the Rust test suite used
  by CI before tagging.
- Build desktop installers and smoke test one installed artifact outside the dev
  server, including startup, single-instance focus, model detection, and audio
  playback.
- Import one HTML, EPUB, and text-native PDF individually and as a multi-file
  batch. Verify progress, cancellation, partial failures, metadata editing,
  gallery/list display, search indexing, and bulk deletion.
- Open representative HTML, EPUB, and PDF documents. Verify Find, exact-phrase
  navigation, bookmarks, zoom/layout changes, and light/dark themes.
- Verify a large HTML/EPUB Find operation remains responsive while typing.
- Save and play an audiobook from each supported document format. Confirm chunk
  highlighting, background title metadata, saved-version selection, export,
  bundle re-import, and source-deletion protection.
- Test multilingual Kokoro selection and labels, Arabic RTL layout, and every
  UI locale's basic Search, Library, Reader, Audiobooks, and Settings flows.
- Transfer a library between two devices over the local network, then repeat
  with a transfer file. Test with no audiobooks, selected audiobooks, cancel,
  resume, insufficient disk space, and a rebuilt search index.
- On Linux x64, install/probe the existing SILMA CPU runtime and save a short
  Arabic audiobook. Treat the local CUDA installer as developer-tested support
  until validated on representative NVIDIA hardware.
- Run Android and iOS CI builds to verify shared Rust, PDF.js assets, localized
  resources, and native TTS preparation remain packageable.
