# Papercut v1.5.2 - Release Notes

- **Target release:** 1.5.2
- **Release branch:** `branch-release-v1.5.2`

Papercut v1.5.2 is a focused iOS native-audiobook patch release. It keeps the v1.5.1 mobile/WebKit fixes intact while completing the iOS packaging path for Arabic Piper audiobook generation with Libtashkeel preprocessing.

## Fixes

- **Enabled Arabic auto-diacritization on iOS native TTS.** iOS native builds now use the dedicated `native-tts-ios` feature, which combines sherpa static linking with the Libtashkeel preprocessing backend.
- **Fixed iOS ONNX Runtime linkage for simulator and device builds.** The generated Xcode Rust build phase now exports `ORT_LIB_LOCATION` alongside `SHERPA_ONNX_LIB_DIR`, so `ort-sys` uses the prepared iOS ONNX Runtime archive instead of trying to download unsupported simulator binaries.
- **Fixed Libtashkeel feature gates for static iOS builds.** Runtime preprocessing and Piper model capability metadata now gate on `native-text-preprocessing-core`, allowing static iOS builds to advertise and use `libtashkeel-1.5.0` while desktop and Android keep their dynamic ONNX Runtime path.
- **Documented the remaining imported-bundle limitation.** Completed audiobook bundles already contain WAV audio, but current import validation can still reject bundles whose stored preprocessor is unsupported by the active runtime. That compatibility behavior is documented for a future playback/import fix.
