# Papercut v1.7.2 - Release Notes

- **Target release:** 1.7.2

Papercut v1.7.2 is a Linux desktop patch release for the optional SILMA Arabic
TTS runtime pack.

## Fixed

- **Packaged SILMA runtime can load the model.** The Linux runtime pack now keeps
  `x_transformers` modules available as Python source so TorchScript can inspect
  functions such as `softclamp` during SILMA model loading.

## Verification

- Build and attach fresh v1.7.2 SILMA runtime pack parts.
- Install the v1.7.2 Linux `.deb` from a clean Papercut app-data/cache state.
- Install SILMA from Audio Setup, probe the sidecar, and save a short Arabic
  audiobook.
