# Papercut v1.9.1 - Release Notes

This patch repairs Kokoro voice-model downloads that failed with a checksum
mismatch after the upstream archive changed. Update Papercut, then retry the
download in the app. Clearing the cache in an older app cannot fix its embedded
checksum. Already installed models remain usable; no library reset is needed.

## Fixed

- Kokoro downloads now use a pinned, immutable Papercut-hosted archive, with an
  upstream fallback for connection or HTTP failures before downloading begins.
  Both sources must match the same exact size and SHA-256 before extraction.
- Supertonic downloads use the archive's exact size instead of an estimate.
- Windows builds reuse Sherpa's ONNX Runtime instead of requesting an unavailable
  upstream binary. Linux native development also uses the configured runtime.
- Android CI explicitly installs supported SDK packages, avoiding obsolete tools.

## Security and maintenance

- Update Rustls and its WebPKI dependency, Vitest and its companion packages,
  and npm transitive dependencies to address the reported security advisories.
- Share model archive identities between the app and automated checks. Hourly
  metadata checks and daily fresh-download synthesis tests detect availability
  or integrity problems; app releases require valid published model metadata.

## Compatibility

Kokoro remains v1.0. This repair does not silently upgrade it to v1.1 or change
the app's voice catalog. Piper and Supertonic still download from their upstream
locations. Interrupted or invalid downloads are cleaned up and start fresh on
retry; resumable downloads and a remotely updated model catalog are not included.
