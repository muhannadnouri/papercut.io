डेमो

ऑफ़लाइन आवाज़ का नमूना

अंतिम डेमो ऑडियो तैयार होने पर यहाँ अंग्रेज़ी में Kokoro का छोटा नमूना और अरबी का नमूना रखें।

ऑडियो नमूने के लिए स्थान

विशेषताएँ

Papercut एक क्रम में काम करता है: अपने दस्तावेज़ आयात करें, उनमें खोजें, महत्वपूर्ण सामग्री पढ़ें और जब सुनना अधिक सुविधाजनक हो तब पोर्टेबल ऑडियो बनाएँ।

खोजें

अपनी पूरी लाइब्रेरी में टेक्स्ट खोजें

इंटरनेट या खाते के बिना सैकड़ों आयातित दस्तावेज़ों की अनुक्रमित सामग्री खोजें। सटीक और व्यापक खोज से नोट्स, कोड संदर्भ, शोध उद्धरण और मैनुअल के अनुभाग पाए जा सकते हैं।

पढ़ें

HTML, EPUB और PDF फ़ाइलें ऑफ़लाइन पढ़ें

अपने दस्तावेज़ों को स्थानीय HTML, EPUB और अनुकूल PDF रीडर में खोलें। रीफ़्लो होने वाले टेक्स्ट के लिए फ़ॉन्ट, पढ़ने की चौड़ाई और गहरी थीम समायोजित करें, जबकि PDF अपने मूल पृष्ठ बनाए रखते हैं।

व्यवस्थित करें

दस्तावेज़, फ़ोल्डर और ऑडियो साथ रखें

एक साथ कई फ़ाइलें आयात करें, कवर या सूची में ब्राउज़ करें, फ़ोल्डर व्यवस्थित करें, शीर्षक संपादित करें, बनाया गया ऑडियो सहेजें और चुने हुए दस्तावेज़ व ऑडियोबुक Papercut डिवाइसों के बीच ले जाएँ।

ऑफ़लाइन ऑडियोबुक

सुनें

अपनी लाइब्रेरी के दस्तावेज़ों से ऑडियोबुक बनाएँ

जब पढ़ना सुविधाजनक न हो, Papercut समर्थित दस्तावेज़ों को आपके डिवाइस पर सहेजे गए ऑडियो में बदल सकता है। आवाज़ मॉडल तभी डाउनलोड होते हैं जब आप ऑडियो उपयोग करना चुनते हैं; इसके बाद निर्माण और प्लेबैक इंटरनेट के बिना काम करते हैं।

निजी निर्माण क्लाउड प्रोसेसिंग, दस्तावेज़ अपलोड या खाते की आवश्यकता नहीं।
उपयोग का कोई मीटर नहीं कोई सदस्यता, API कुंजी, टोकन सीमा या प्रति-अक्षर शुल्क नहीं।
निर्यात और आयात ऑडियोबुक बंडल साझा करने, स्थानांतरित करने या किसी दूसरे डिवाइस पर Papercut में वापस लाने के लिए सहेजें।
कहीं भी सुनें Android पृष्ठभूमि और लॉक-स्क्रीन प्लेबैक का समर्थन करता है।

बहुभाषी Kokoro आवाज़ें

Kokoro अंग्रेज़ी, मंदारिन चीनी, स्पेनिश, फ़्रेंच, हिन्दी, इतालवी और ब्राज़ीलियाई पुर्तगाली के लिए ऑफ़लाइन आवाज़ें देता है।

अरबी आवाज़ें

अरबी अलग ऑफ़लाइन Piper और Supertonic मॉडल उपयोग करती है। Linux x64 पर Papercut द्वारा प्रबंधित वैकल्पिक रनटाइम डाउनलोड के माध्यम से SILMA भी उपलब्ध है।

ऑफ़लाइन मॉडल का दायरा

अभी ऑफ़लाइन मॉडल ऑडियोबुक निर्माण करते हैं। खोज, आयात और पढ़ना स्थानीय दस्तावेज़ उपकरण बने रहते हैं।

गोपनीयता मॉडल

डिफ़ॉल्ट रूप से स्थानीय

आपकी लाइब्रेरी आपके डिवाइस पर रहती है

Papercut आयातित दस्तावेज़, खोज, पढ़ना और बनाया गया ऑडियो डिफ़ॉल्ट रूप से स्थानीय रखता है। नेटवर्क पहुँच केवल आपके चुने हुए कार्यों तक सीमित है, जैसे आवाज़ मॉडल या रिलीज़ फ़ाइल डाउनलोड करना।

दस्तावेज़ आयातित HTML, EPUB और PDF फ़ाइलें स्थानीय रहती हैं।
खोज लाइब्रेरी खोज स्थानीय दस्तावेज़ सामग्री पर चलती है।
ऑडियोबुक बनाया गया ऑडियो स्थानीय रहता है और Papercut उस पर स्वामित्व का दावा नहीं करता।
नेटवर्क केवल आपके अनुरोध पर आवाज़ मॉडल, रिलीज़ या बाहरी संसाधन डाउनलोड करने के लिए उपयोग होता है।

उपयोग के तरीके

Papercut सहेजे गए दस्तावेज़ों, पुस्तकों, नोट्स, मैनुअल और शोध सामग्री से बनी निजी लाइब्रेरी के लिए उपयुक्त है। यह खोज, पढ़ने और सुनने को आपकी मौजूदा फ़ाइलों के पास रखता है।

Papercut से सबसे अधिक लाभ किसे मिलता है?

डेवलपर API दस्तावेज़, मैनुअल और सहेजे गए संदर्भ ऑफ़लाइन खोजें।
शोधकर्ता शोध-पत्र, नोट्स और लंबे स्रोत खोजने और सुनने योग्य रखें।
विद्यार्थी पठन सामग्री, EPUB और टेक्स्ट-आधारित PDF को निजी अध्ययन ऑडियो में बदलें।
ऑफ़लाइन को प्राथमिकता देने वाले पाठक स्थानीय उपकरण, कम खाते और कम क्लाउड निर्भरता पसंद करें।

तुलना

इसके बजाय Papercut क्यों उपयोग करें?

क्लाउड TTS सेवाएँ कोई अपलोड, API कुंजी, सदस्यता या उपयोग मीटर नहीं।
ऑडियोबुक ऐप कैटलॉग से खरीदने के बजाय अपने दस्तावेज़ों से ऑडियो बनाएँ।
दस्तावेज़ रीडर अनेक दस्तावेज़ों में खोज, लाइब्रेरी स्थानांतरण और ऑफ़लाइन ऑडियोबुक निर्माण जोड़ें।
AI रीडर ऐप दस्तावेज़ों को चैट-केंद्रित क्लाउड उपकरणों में अपलोड करने के बजाय लाइब्रेरी खोज, पढ़ना और ऑडियोबुक निर्माण स्थानीय रखें।

सामान्य प्रश्न

ऑफ़लाइन ऑडियो, गोपनीयता, समर्थित फ़ाइलों और प्रत्येक प्लेटफ़ॉर्म पर Papercut स्थापित करने की व्यावहारिक जानकारी।

क्या Papercut ऑडियोबुक के अलावा किसी और काम के लिए AI उपयोग करता है?

अभी ऑफ़लाइन मॉडल ऑडियोबुक निर्माण के लिए उपयोग होते हैं। पढ़ना, आयात, व्यवस्था और खोज स्थानीय दस्तावेज़ उपकरण हैं।

Papercut को इंटरनेट की आवश्यकता कब होती है?

पढ़ना और खोज ऑफ़लाइन काम करते हैं। नेटवर्क पहुँच तब उपयोग होती है जब आप आवाज़ मॉडल या रिलीज़ डाउनलोड करते हैं अथवा कोई बाहरी संसाधन खोलते हैं। यदि आप ऑडियोबुक नहीं बनाते, तो आवाज़ मॉडल डाउनलोड करने की आवश्यकता नहीं है।

अंग्रेज़ी ऑडियोबुक निर्माण Kokoro क्यों उपयोग करता है?

अंग्रेज़ी आवाज़ें Kokoro उपयोग करती हैं क्योंकि यह अभी पूरी तरह ऑफ़लाइन आवाज़ मॉडलों में अच्छी गुणवत्ता देता है। उद्देश्य क्लाउड प्रोसेसिंग, सदस्यता, API कुंजी या प्रति-अक्षर शुल्क के बिना स्वाभाविक ऑडियो बनाना है।

अरबी ऑडियोबुक समर्थन कैसे काम करता है?

अरबी अलग ऑफ़लाइन मॉडलों से समर्थित है। Piper छोटा और अनेक प्लेटफ़ॉर्म पर चलने वाला विकल्प है, जबकि SILMA वैकल्पिक रनटाइम डाउनलोड से Linux x64 डेस्कटॉप पर उपलब्ध है।

बनाए गए ऑडियो का स्वामी कौन है?

Papercut बनाए गए ऑडियो पर स्वामित्व का दावा नहीं करता। स्रोत पाठ, उपयोग की गई संदर्भ आवाज़ या रिकॉर्डिंग और निर्यातित ऑडियो साझा करने के अधिकारों के लिए आप उत्तरदायी हैं। Papercut ऑडियोबुक आउटपुट स्थानीय रूप से सहेजता है और उसे किसी सेवा पर अपलोड नहीं करता।

क्या मैं बनाए गए ऑडियोबुक स्थानांतरित या साझा कर सकता हूँ?

हाँ। सहेजे गए ऑडियोबुक Papercut बंडल के रूप में निर्यात किए जा सकते हैं, फिर साझा, दूसरे डिवाइस पर स्थानांतरित, बैकअप या बाद में Papercut में फिर आयात किए जा सकते हैं। बनाए गए ऑडियो को साझा, प्रकाशित, बेचने या प्रसारित करने पर उसे AI-निर्मित बताएँ और प्रतिरूपण या भ्रमित करने के लिए उपयोग न करें।

क्या मैं किसी भी आवाज़ की नकल या संदर्भ ले सकता हूँ?

नहीं। संदर्भ-आवाज़ सुविधाएँ केवल उन आवाज़ों और रिकॉर्डिंग के साथ उपयोग करें जिनके लिए आपके पास अधिकार या अनुमति है।

कौन से दस्तावेज़ प्रारूप समर्थित हैं?

Papercut HTML, EPUB और PDF फ़ाइलें आयात करता है। PDF खोज, Find और ऑडियोबुक निर्माण के लिए अंतर्निहित टेक्स्ट आवश्यक है; केवल चित्र वाले PDF समर्थित होने पर देखे जा सकते हैं, लेकिन खोजे नहीं जा सकते क्योंकि Papercut में अभी OCR शामिल नहीं है।

कौन सी इंटरफ़ेस भाषाएँ उपलब्ध हैं?

Papercut अंग्रेज़ी, अरबी, सरलीकृत चीनी, स्पेनिश, फ़्रेंच, हिन्दी, इतालवी और ब्राज़ीलियाई पुर्तगाली में उपलब्ध है।

कौन सी ऑडियोबुक भाषाएँ उपलब्ध हैं?

Kokoro अंग्रेज़ी, मंदारिन चीनी, स्पेनिश, फ़्रेंच, हिन्दी, इतालवी और ब्राज़ीलियाई पुर्तगाली के लिए आवाज़ें देता है। अरबी अलग ऑफ़लाइन Piper और Supertonic मॉडल उपयोग करती है, और SILMA वैकल्पिक रनटाइम से Linux x64 पर उपलब्ध है।

सिस्टम आवश्यकताएँ क्या हैं?

Android: arm64-v8a डिवाइसों पर Android 8.0 / API 26 या नया।

iOS: नियोजित है, App Store रिलीज़ जल्द आ रही है।

macOS: Apple Silicon या Intel Mac पर macOS 10.13 या नया।

Linux: WebKitGTK और GStreamer उपलब्ध वाला amd64 Linux; रिलीज़ फ़ाइलें Ubuntu 24.04 पर बनाई जाती हैं।

Windows: Microsoft Edge WebView2 रनटाइम के साथ Windows 10 या नया x64।

Android

अपने ब्राउज़र या फ़ाइल प्रबंधक की सेटिंग में अज्ञात ऐप इंस्टॉल करें चालू करें, फिर APK खोलें। पढ़ना और खोज ऑफ़लाइन काम करते हैं। नेटवर्क पहुँच केवल आवाज़ मॉडल डाउनलोड करने पर उपयोग होती है; ऑडियोबुक निर्माण न उपयोग करने पर नेटवर्क की आवश्यकता नहीं है।

Linux

WebKitGTK और GStreamer उपलब्ध वाला amd64 Linux आवश्यक है। रिलीज़ फ़ाइलें Ubuntu 24.04 पर बनाई जाती हैं।

Debian-आधारित (Ubuntu, Mint): sudo apt install ./Papercut_*.deb

RPM-आधारित (Fedora, openSUSE): sudo rpm -i Papercut-*.rpm

AppImage: निष्पादन योग्य बनाएँ (chmod +x) और सीधे चलाएँ। Arch-आधारित प्रणालियों पर AppImage को WEBKIT_DISABLE_COMPOSITING_MODE=1 की आवश्यकता हो सकती है; विवरण के लिए README देखें।

macOS

Apple Silicon या Intel Mac पर macOS 10.13 या नया आवश्यक है। .dmg खोलें और Papercut को Applications फ़ोल्डर में खींचें। आधिकारिक रिलीज़ बिल्ड Developer ID से हस्ताक्षरित और नोटराइज़्ड हैं। अहस्ताक्षरित CI या स्थानीय विकास बिल्ड जाँचते समय ऐप आइकन पर दायाँ-क्लिक (या Control-क्लिक) करें और पहली बार खोलें चुनें।

अपने Mac के अनुरूप बिल्ड चुनें: Apple Silicon (_aarch64.dmg) M-सीरीज़ चिप के लिए, या Intel (_x64.dmg) Intel-आधारित Mac के लिए।

Windows

x64 हार्डवेयर पर Windows 10 या नया और Microsoft Edge WebView2 रनटाइम आवश्यक है। MSI इंस्टॉलर सेटअप अपने आप करता है। पोर्टेबल EXE चाहें तो उसे सीधे चलाएँ। व्यवस्थापक अधिकार आवश्यक नहीं हैं।

दस्तावेज़, रिलीज़ और स्रोत कोड कहाँ मिलेंगे?

सेटअप सहायता और प्लेटफ़ॉर्म जानकारी के लिए README से शुरू करें। नया क्या है जानने के लिए रिलीज़ नोट्स देखें, सभी रिलीज़ ब्राउज़ करें या GitHub पर योगदान दें।
