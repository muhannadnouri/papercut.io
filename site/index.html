Features

Papercut works as a loop: import your documents, search across them, read what matters, and make portable audio when listening fits better.

Search

Find text across your whole library

Search across hundreds of imported documents without internet, accounts, or waiting. Exact and fuzzy search help you recover notes, code references, research quotes, and manual sections.

Read

Read HTML and EPUB files offline

Bring your own HTML and EPUB files into a fast local reader. Tune the experience with fonts and dark mode so books, documentation, papers, and long notes stay comfortable.

Organize

Keep documents, folders, and audio together

Organize files into folders, save generated audio, and export audiobook bundles for sharing, transfer, or backup. PDF support is coming soon.

Offline Audiobooks

Listen

Generate audiobooks from documents in your library

When reading is not the right mode, Papercut can turn supported documents into saved audio on your device. Voice models download only when you choose to use audio; after that, generation and playback work without internet.

Private generation No cloud processing, document upload, or account required.
No rental meter No subscription, API key, token limit, or per-character bill.
Export and import Save audiobook bundles to share, transfer, or bring back into Papercut on another device.
Listen anywhere Android supports background and lock-screen playback.

English voices

English audiobook generation uses Kokoro because it currently offers strong quality among fully offline voice models.

Arabic voices

Arabic is supported with separate offline models, not Kokoro, so language support is explicit instead of hidden in a generic AI claim.

Offline model scope

Today, offline models power audiobook generation. Search, import, and reading remain local document tools.

Privacy Model

Local-first by default

Your library stays on your device

Papercut keeps imported documents, search, reading, and generated audio local by default. Network access is limited to actions you choose, such as downloading voice models or fetching release files.

Documents Imported HTML and EPUB files remain local.
Search Library search runs against local document content.
Audiobooks Generated audio is saved locally and owned by you.
Network Used only when you download voice models, releases, or external resources you request.

Use Cases

Papercut fits personal libraries built from saved documents, books, notes, manuals, and research material. It keeps search, reading, and listening close to the files you already use.

FAQ

Practical details about offline audio, privacy, supported files, and installing Papercut on each platform.

Does Papercut use AI for anything besides audiobooks?

Currently, offline models are used for audiobook generation. Reading, import, organization, and search are local document tools.

When does Papercut need internet access?

Reading and search work offline. Network access is used when you choose to download a voice model, download a release, or open an external resource. If you do not use audiobook generation, voice model downloads are not needed.

Why does English audiobook generation use Kokoro?

English voices use Kokoro because it currently offers strong quality among fully offline voice models. The goal is natural-sounding audio without cloud processing, subscriptions, API keys, or per-character billing.

How does Arabic audiobook support work?

Arabic is supported with separate offline models. It does not use Kokoro, so language support and model expectations stay clear.

Who owns generated audio?

You own the generated audio. Papercut saves audiobook output locally and does not upload it to a service.

Can I move or share generated audiobooks?

Yes. Saved audiobooks can be exported as Papercut audiobook bundles, then shared, transferred to another device, backed up, or imported back into Papercut later.

Which document formats are supported?

Papercut currently imports HTML and EPUB files. PDF support is planned.

What are the system requirements?

Android: Android 8.0 / API 26+ on arm64-v8a devices.

iOS: planned, App Store release coming soon.

macOS: macOS 10.13+ on Apple Silicon or Intel Macs.

Linux: amd64 Linux with WebKitGTK and GStreamer available; release artifacts are built on Ubuntu 24.04.

Windows: Windows 10+ x64 with the Microsoft Edge WebView2 runtime.

Android

Enable Install unknown apps in Settings for your browser or file manager, then open the APK. Reading and search work offline. Network access is only used if you choose to download a voice model; if you do not use audiobook generation, network access is not needed.

Linux

Requires amd64 Linux with WebKitGTK and GStreamer available. Release artifacts are built on Ubuntu 24.04.

Debian-based (Ubuntu, Mint): sudo apt install ./Papercut_*.deb

RPM-based (Fedora, openSUSE): sudo rpm -i Papercut-*.rpm

AppImage: make executable (chmod +x) and run directly. On Arch-based systems the AppImage may need WEBKIT_DISABLE_COMPOSITING_MODE=1; see the README for details.

macOS

Requires macOS 10.13+ on Apple Silicon or Intel Macs. Open the .dmg and drag Papercut to your Applications folder. Official release builds are Developer ID signed and notarized. If you are testing an unsigned CI or local development artifact, right-click (or Control-click) the app icon and choose Open on first launch.

Pick the build that matches your Mac: Apple Silicon (_aarch64.dmg) for M-series chips, or Intel (_x64.dmg) for Intel-based Macs.

Windows

Requires Windows 10+ on x64 hardware and the Microsoft Edge WebView2 runtime. The MSI installer handles setup automatically. If you prefer the portable EXE, run it directly. No admin rights needed.
