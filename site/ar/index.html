مكان مخصص لعينة صوتية

الميزات

يعمل Papercut كحلقة متكاملة: استورد مستنداتك، وابحث فيها، واقرأ ما يهمك، وأنشئ صوتًا محمولًا عندما يكون الاستماع أنسب.

البحث

اعثر على النص في مكتبتك كلها

ابحث في المحتوى المفهرس عبر مئات المستندات المستوردة دون إنترنت أو حسابات. يساعدك البحث الدقيق والواسع على استرجاع الملاحظات ومراجع الشيفرة واقتباسات الأبحاث وأقسام الأدلة.

القراءة

اقرأ ملفات HTML وEPUB وPDF بلا اتصال

أضف مستنداتك إلى قارئات HTML وEPUB وPDF المحلية. تحتفظ ملفات PDF بصفحاتها الأصلية، ويمكن للتعرف الضوئي بلا اتصال جعل الصفحات الممسوحة بالإنجليزية أو العربية قابلة للبحث والاستماع.

التنظيم

احتفظ بالمستندات والمجلدات والصوت معًا

استورد ملفات كثيرة دفعة واحدة، وتصفح الأغلفة أو القوائم، ونظّم المجلدات، وعدّل العناوين، واحفظ الصوت المولّد، وانقل المستندات والكتب الصوتية المختارة بين أجهزة Papercut.

الكتب الصوتية بلا اتصال

استمع

أنشئ كتبًا صوتية من مستندات مكتبتك

عندما لا تكون القراءة هي الخيار الأنسب، يستطيع Papercut تحويل المستندات المدعومة إلى صوت محفوظ على جهازك. لا تُنزّل النماذج الصوتية إلا عند اختيارك استخدام الصوت؛ وبعد ذلك يعمل التوليد والتشغيل بلا إنترنت.

إنشاء خاص لا معالجة سحابية ولا رفع للمستندات ولا حاجة إلى حساب.
دون رسوم استخدام لا اشتراك ولا مفتاح API ولا حد للرموز ولا رسوم لكل حرف.
تصدير واستيراد احفظ حزم الكتب الصوتية لمشاركتها أو نقلها أو استيرادها مجددًا إلى Papercut على جهاز آخر.
استمع في أي مكان يدعم Android التشغيل في الخلفية ومن شاشة القفل.

أصوات Kokoro متعددة اللغات

يوفر Kokoro أصواتًا بلا اتصال للإنجليزية والصينية المندرينية والإسبانية والفرنسية والهندية والإيطالية والبرتغالية البرازيلية.

الأصوات العربية

تستخدم العربية نماذج Piper وSupertonic منفصلة بلا اتصال. ويتوفر SILMA أيضًا على Linux x64 عبر تنزيل اختياري لبيئة التشغيل يديره Papercut.

نطاق النماذج بلا اتصال

تُستخدم النماذج بلا اتصال حاليًا لإنشاء الكتب الصوتية. ويظل البحث والاستيراد والقراءة أدوات محلية للمستندات.

نموذج الخصوصية

محلي أولًا بصورة افتراضية

تبقى مكتبتك على جهازك

يحتفظ Papercut بالمستندات المستوردة والبحث والقراءة والصوت المولّد محليًا بصورة افتراضية. ويقتصر الوصول إلى الشبكة على الإجراءات التي تختارها، مثل تنزيل النماذج الصوتية أو ملفات الإصدارات.

المستندات تبقى ملفات HTML وEPUB وPDF المستوردة محلية.
البحث يعمل البحث في المكتبة على محتوى المستندات المحلي.
الكتب الصوتية يبقى الصوت المولّد محليًا، ولا يدّعي Papercut ملكيته.
الشبكة تُستخدم فقط عند تنزيل النماذج الصوتية أو الإصدارات أو الموارد الخارجية التي تطلبها.

الاستخدامات

يناسب Papercut المكتبات الشخصية المبنية من المستندات والكتب والملاحظات والأدلة والمواد البحثية المحفوظة. فهو يبقي البحث والقراءة والاستماع قريبًا من الملفات التي تستخدمها بالفعل.

من يستفيد أكثر من Papercut؟

المطورون ابحث في وثائق API والأدلة والمراجع المحفوظة بلا اتصال.
الباحثون اجعل الأوراق والملاحظات والمصادر المطوّلة قابلة للبحث والاستماع.
الطلاب حوّل حزم القراءة وملفات EPUB وPDF، بما فيها الصفحات الممسوحة التي تم التعرف عليها، إلى صوت دراسي خاص.
القراء الذين يفضلون العمل بلا اتصال استخدم أدوات محلية وحسابات أقل واعتمادًا أقل على السحابة.

مقارنةً بـ

لماذا تستخدم Papercut بدلًا من ذلك؟

خدمات تحويل النص إلى كلام السحابية لا رفع للملفات ولا مفاتيح API ولا اشتراكات ولا عدّادات استخدام.
تطبيقات الكتب الصوتية أنشئ صوتًا من مستنداتك بدلًا من الشراء من فهرس.
قارئات المستندات احصل على البحث عبر المستندات ونقل المكتبة وإنشاء الكتب الصوتية بلا اتصال.
تطبيقات القراءة بالذكاء الاصطناعي أبقِ بحث المكتبة والقراءة وإنشاء الكتب الصوتية محليًا بدلًا من رفع المستندات إلى أدوات سحابية تتمحور حول المحادثة.

الأسئلة الشائعة

تفاصيل عملية عن الصوت بلا اتصال والخصوصية والملفات المدعومة وتثبيت Papercut على كل منصة.

هل يستخدم Papercut الذكاء الاصطناعي في شيء غير الكتب الصوتية؟

نعم. يستخدم Papercut أيضًا التعرف الضوئي المضمّن على الجهاز للتعرف على النص الإنجليزي أو العربي في صفحات PDF المصورة والمختلطة. لا يرفع التعرف الضوئي أو إنشاء الكتب الصوتية مستنداتك إلى خدمة سحابية.

متى يحتاج Papercut إلى الاتصال بالإنترنت؟

تعمل القراءة والبحث بلا اتصال. يُستخدم اتصال الشبكة عندما تختار تنزيل نموذج صوتي أو إصدار أو فتح مورد خارجي. وإذا لم تستخدم إنشاء الكتب الصوتية فلن تحتاج إلى تنزيل النماذج الصوتية.

لماذا تستخدم الكتب الصوتية الإنجليزية Kokoro؟

تستخدم الأصوات الإنجليزية Kokoro لأنه يقدم حاليًا جودة قوية بين النماذج الصوتية التي تعمل بلا اتصال تمامًا. والهدف هو صوت طبيعي دون معالجة سحابية أو اشتراكات أو مفاتيح API أو رسوم لكل حرف.

كيف يعمل دعم الكتب الصوتية العربية؟

تُدعم العربية بنماذج مستقلة تعمل بلا اتصال. Piper هو الخيار الأصغر متعدد المنصات، بينما يتوفر SILMA على سطح مكتب Linux x64 عبر تنزيل اختياري لبيئة التشغيل.

من يملك الصوت المولّد؟

لا يدّعي Papercut ملكية الصوت المولّد. أنت مسؤول عن حقوق النص المصدر وأي صوت مرجعي أو تسجيل مستخدم وطريقة مشاركة الصوت المصدّر. يحفظ Papercut ناتج الكتاب الصوتي محليًا ولا يرفعه إلى خدمة.

هل يمكنني نقل الكتب الصوتية المولّدة أو مشاركتها؟

نعم. يمكن تصدير الكتب الصوتية المحفوظة كحزم Papercut ثم مشاركتها أو نقلها إلى جهاز آخر أو نسخها احتياطيًا أو استيرادها مجددًا لاحقًا. إذا شاركت الصوت المولّد أو نشرته أو بعته أو بثثته، فضع عليه علامة توضح أنه مولّد بالذكاء الاصطناعي ولا تستخدمه للانتحال أو التضليل.

هل يمكنني استنساخ أي صوت أو استخدامه كمرجع؟

لا. يجب استخدام ميزات الصوت المرجعي فقط مع الأصوات والتسجيلات التي تملك حقوق استخدامها أو إذنًا بذلك.

ما تنسيقات المستندات المدعومة؟

يستورد Papercut ملفات HTML وEPUB وPDF. تكون ملفات PDF ذات النص المضمّن قابلة للبحث فورًا، ويمكن التعرف على الصفحات المصورة والمختلطة بالإنجليزية أو العربية عند الطلب دون اتصال. ويمكن لأجهزة Android المدعومة أيضًا مسح الصفحات أو استيراد الصور إلى ملف PDF.

ما لغات الواجهة المتوفرة؟

يتوفر Papercut بالإنجليزية والعربية والصينية المبسطة والإسبانية والفرنسية والهندية والإيطالية والبرتغالية البرازيلية.

ما لغات الكتب الصوتية المتوفرة؟

يوفر Kokoro أصواتًا للإنجليزية والصينية المندرينية والإسبانية والفرنسية والهندية والإيطالية والبرتغالية البرازيلية. وتستخدم العربية نماذج Piper وSupertonic مستقلة بلا اتصال، مع توفر SILMA على Linux x64 عبر بيئة تشغيل اختيارية.

ما متطلبات النظام؟

Android: ‏Android 8.0 / API 26 أو أحدث على أجهزة arm64-v8a.

iOS: مخطط له، وسيصدر على App Store قريبًا.

macOS: ‏macOS 10.13 أو أحدث على أجهزة Mac بمعالجات Apple Silicon أو Intel.

Linux: ‏Linux بمعمارية amd64 مع توفر WebKitGTK وGStreamer؛ وتُبنى ملفات الإصدار على Ubuntu 24.04.

Windows: ‏Windows 10 أو أحدث بمعمارية x64 مع بيئة تشغيل Microsoft Edge WebView2.

Android

فعّل تثبيت التطبيقات غير المعروفة في إعدادات المتصفح أو مدير الملفات، ثم افتح ملف APK. تعمل القراءة والبحث بلا اتصال. ولا يُستخدم اتصال الشبكة إلا إذا اخترت تنزيل نموذج صوتي؛ وإذا لم تستخدم إنشاء الكتب الصوتية فلن تحتاج إلى الشبكة.

Linux

يتطلب Linux بمعمارية amd64 مع توفر WebKitGTK وGStreamer. وتُبنى ملفات الإصدار على Ubuntu 24.04.

التوزيعات المبنية على Debian مثل Ubuntu وMint: sudo apt install ./Papercut_*.deb

التوزيعات المبنية على RPM مثل Fedora وopenSUSE: sudo rpm -i Papercut-*.rpm

AppImage: اجعله قابلًا للتنفيذ باستخدام chmod +x ثم شغّله مباشرة. قد يحتاج AppImage على الأنظمة المبنية على Arch إلى WEBKIT_DISABLE_COMPOSITING_MODE=1؛ راجع ملف README للتفاصيل.

macOS

يتطلب macOS 10.13 أو أحدث على أجهزة Mac بمعالجات Apple Silicon أو Intel. افتح ملف .dmg واسحب Papercut إلى مجلد التطبيقات. إصدارات النشر الرسمية موقّعة بمعرّف مطور وموثّقة. إذا كنت تختبر ملفًا غير موقّع من CI أو تطوير محلي، فانقر بزر الفأرة الأيمن أو مع الضغط على Control على أيقونة التطبيق واختر فتح عند التشغيل الأول.

اختر الإصدار المطابق لجهازك: Apple Silicon ‏(_aarch64.dmg) لشرائح الفئة M، أو Intel ‏(_x64.dmg) لأجهزة Mac المبنية على Intel.

Windows

يتطلب Windows 10 أو أحدث على أجهزة x64 وبيئة تشغيل Microsoft Edge WebView2. يتولى مثبّت MSI الإعداد تلقائيًا. وإذا كنت تفضل ملف EXE المحمول فشغّله مباشرة. لا يلزم امتلاك صلاحيات المسؤول.
