下载 使用方式

从搜索结果到段落朗读

查找

在全文中搜索关键词或完全匹配的短语。

如果只记得大意，可以试试基于嵌入向量的语义搜索，找到意思相近的段落。

阅读

打开结果，跳到对应段落继续阅读。

为段落添加书签，下次打开文档时就能回到这里。

收听

从这一段开始播放已保存的有声书。

听朗读时可以跟着高亮文字阅读，也可以在朗读继续时先往下读。

导入自己的文档库

在本地 HTML、EPUB、PDF、TXT 和 Markdown 阅读器中打开您的文档。PDF 保留原始页面，离线 OCR 则可让英语或阿拉伯语扫描页面支持搜索和朗读。

一次导入多个文件，通过封面或列表浏览，整理文件夹，编辑标题，保存生成的音频，并在 Papercut 设备之间传输所选文档和有声读物。

制作自己的有声书

语音下载一次后，就能在设备上生成和播放有声书，无需订阅，也不按用量收费。

保存有声读物包，以便分享、传输或在另一台设备上重新导入 Papercut。

声音与语言

默认保护隐私

导入、搜索、阅读和生成有声书都在设备上完成。应用内置 PDF 英语和阿拉伯语文字识别功能，可离线使用。

下载和打开外部链接需要互联网连接。选择直接向另一台设备发送书籍或音频时，传输使用本地网络。

常见问题

了解离线音频、隐私、支持的文件格式，以及在各个平台上安装 Papercut 的实用信息。

文档库与隐私

支持哪些文档格式？

Papercut 可导入 HTML、EPUB、PDF、TXT 和 Markdown 文件。含嵌入文本的 PDF 可立即搜索；纯图像和混合页面可按需通过离线 OCR 识别英语或阿拉伯语。受支持的 Android 设备还可扫描页面或将照片导入 PDF。

Papercut 除了制作有声读物，还会将 AI 用于其他功能吗？

会。Papercut 还使用设备内置 OCR 来识别纯图像或混合 PDF 页面中的英语或阿拉伯语文本。OCR 和有声读物生成都不会把您的文档上传到云服务。

如需按含义搜索，请下载可选的搜索模型，启用实验性语义搜索，并在设备上建立索引。之后即可离线搜索。

Papercut 何时需要访问互联网？

下载和打开外部链接需要互联网连接。选择直接向另一台设备发送书籍或音频时，传输使用本地网络。

声音与语言

界面支持哪些语言？

Papercut 提供英语、阿拉伯语、简体中文、西班牙语、法语、印地语、意大利语和巴西葡萄牙语界面。

有声读物支持哪些语言？

Kokoro 支持英语，并提供普通话、西班牙语、法语、印地语、意大利语和巴西葡萄牙语的实验性语音。Supertonic 提供英语和阿拉伯语的实验性语音。

为什么英语有声读物使用 Kokoro？

Kokoro 是默认英语模型。下载后即可在设备上合成语音，无需 API 密钥，也不按字符收费。

阿拉伯语有声读物如何实现？

Piper Kareem 支持阿拉伯语。Supertonic 是实验性选项。SILMA 需要在 Linux x64 上下载可选运行环境。

音频权利与分享

生成音频的所有权归谁？

Papercut 不主张生成音频的所有权。您需要自行确保拥有源文本、所用参考语音或录音的相关权利，并对导出音频的分享方式负责。Papercut 会将有声读物保存在本地，不会上传到任何服务。

可以移动或分享生成的有声读物吗？

可以。保存的有声读物可导出为 Papercut 有声读物包，用于分享、传输到其他设备、备份，或日后重新导入 Papercut。如果您分享、发布、出售或广播生成的音频，请明确标注其由 AI 生成，且不得用于冒充或误导他人。

可以克隆或引用任何人的声音吗？

不可以。参考语音功能仅应用于您有权或已获许可使用的声音和录音。

安装与支持

系统要求是什么？

Android: arm64-v8a 设备上的 Android 8.0 / API 26 及以上版本。

iOS: 已在计划中，即将登陆 App Store。

macOS: Apple Silicon 或 Intel Mac 上的 macOS 10.13 及以上版本。

Linux: 已安装 WebKitGTK 和 GStreamer 的 amd64 Linux；发布文件在 Ubuntu 24.04 上构建。

Windows: 安装 Microsoft Edge WebView2 运行时的 Windows 10 及以上 x64 系统。

在哪里可以找到文档、发布版本和源代码？

有关设置帮助和平台详情，请先查看 README。您还可以在发布说明中了解新功能，浏览所有发布版本，或在 GitHub 上参与贡献。
