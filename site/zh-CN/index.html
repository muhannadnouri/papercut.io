离线阅读器、搜索引擎和有声读物制作工具

离线搜索、阅读和收听您的文档

Papercut 是一款桌面和移动应用，可导入 HTML、EPUB 和含文本的 PDF 文件，搜索已建立索引的个人资料库，在本地阅读，并生成可导出、 随身携带的离线有声读物。

功能

Papercut 形成一个完整流程：导入文档、跨文档搜索、阅读重要内容，并在更适合收听时制作便携音频。

搜索

在整个资料库中查找文本

无需互联网或账户，即可搜索数百份已导入文档的索引内容。精确搜索和广泛搜索可帮助您找回笔记、代码参考、研究引文和手册章节。

阅读

离线阅读 HTML、EPUB 和 PDF 文件

在本地 HTML、EPUB 和自适应 PDF 阅读器中打开您自己的文档。可调整可重排文本的字体、阅读宽度和深色模式，同时 PDF 保留原始页面。

整理

将文档、文件夹和音频集中管理

一次导入多个文件，通过封面或列表浏览，整理文件夹，编辑标题，保存生成的音频，并在 Papercut 设备之间传输所选文档和有声读物。

离线有声读物

收听

从资料库中的文档生成有声读物

当阅读并非最佳方式时，Papercut 可将支持的文档转换为设备上 保存的音频。只有当您选择使用音频时才会下载语音模型；此后， 生成和播放都无需互联网。

私密生成 无需云端处理、上传文档或创建账户。
没有用量计费 无需订阅、API 密钥，没有令牌上限或按字符收费。
导出和导入 保存有声读物包，以便分享、传输或在另一台设备上重新导入 Papercut。
随处收听 Android 支持后台和锁屏播放。

多语言 Kokoro 语音

Kokoro 为英语、普通话、西班牙语、法语、印地语、意大利语和巴西葡萄牙语提供离线语音。

阿拉伯语语音

阿拉伯语使用独立的离线 Piper 和 Supertonic 模型。Linux x64 还可通过 Papercut 管理的可选运行时下载使用 SILMA。

离线模型的范围

目前，离线模型用于生成有声读物。搜索、导入和阅读仍然是本地文档工具。

隐私模式

默认本地优先

您的资料库保留在设备上

Papercut 默认将导入的文档、搜索、阅读和生成的音频保留在 本地。网络访问仅限于您选择的操作，例如下载语音模型或 获取发布文件。

文档 导入的 HTML、EPUB 和 PDF 文件保留在本地。
搜索 资料库搜索针对本地文档内容运行。
有声读物 生成的音频保留在本地，Papercut 不主张其所有权。
网络 仅在您请求下载语音模型、版本或外部资源时使用。

使用场景

Papercut 适合由已保存文档、书籍、笔记、手册和研究资料构成的个人资料库。它让搜索、阅读和收听紧贴您已经使用的文件。

谁最适合使用 Papercut？

开发者 离线搜索 API 文档、手册和已保存的参考资料。
研究人员 让论文、笔记和长篇资料保持可搜索、可收听。
学生 将阅读资料包、EPUB 和含文本的 PDF 转换为私密学习音频。
离线优先的读者 偏好本地工具、更少账户和更低的云端依赖。

对比

为什么选择 Papercut？

云端 TTS 服务 无需上传、API 密钥、订阅或用量计费。
有声读物应用 从您自己的文档制作音频，而不是从目录购买。
文档阅读器 增加跨文档搜索、资料库传输和离线有声读物生成。
AI 阅读应用 将资料库搜索、阅读和有声读物生成保留在本地，而不是把文档上传到以聊天为中心的云端工具。

常见问题

了解离线音频、隐私、支持的文件格式，以及在各个平台上安装 Papercut 的实用信息。

Papercut 除了制作有声读物，还会将 AI 用于其他功能吗？

目前，离线模型仅用于生成有声读物。阅读、导入、整理和搜索都是本地文档功能。

Papercut 何时需要访问互联网？

阅读和搜索可离线使用。只有当您选择下载语音模型、下载发布版本或打开外部资源时才会访问网络。如果不使用有声读物生成功能，则无需下载语音模型。

为什么英语有声读物使用 Kokoro？

英语语音使用 Kokoro，是因为它目前在完全离线的语音模型中具有较好的质量。目标是在无需云端处理、订阅、API 密钥或按字符计费的情况下生成自然的音频。

阿拉伯语有声读物如何实现？

阿拉伯语使用独立的离线模型。Piper 是体积较小的跨平台选择；在 Linux x64 桌面端，还可通过可选运行时下载使用 SILMA。

生成音频的所有权归谁？

Papercut 不主张生成音频的所有权。您需要自行确保拥有源文本、所用参考语音或录音的相关权利，并对导出音频的分享方式负责。Papercut 会将有声读物保存在本地，不会上传到任何服务。

可以移动或分享生成的有声读物吗？

可以。保存的有声读物可导出为 Papercut 有声读物包，用于分享、传输到其他设备、备份，或日后重新导入 Papercut。如果您分享、发布、出售或广播生成的音频，请明确标注其由 AI 生成，且不得用于冒充或误导他人。

可以克隆或引用任何人的声音吗？

不可以。参考语音功能仅应用于您有权或已获许可使用的声音和录音。

支持哪些文档格式？

Papercut 可导入 HTML、EPUB 和 PDF 文件。PDF 搜索、查找和有声读物生成需要文件包含嵌入文本；在支持的情况下可以查看纯图像 PDF，但由于 Papercut 尚未提供 OCR，这类文件无法搜索。

界面支持哪些语言？

Papercut 提供英语、阿拉伯语、简体中文、西班牙语、法语、印地语、意大利语和巴西葡萄牙语界面。

有声读物支持哪些语言？

Kokoro 为英语、普通话、西班牙语、法语、印地语、意大利语和巴西葡萄牙语提供语音。阿拉伯语使用独立的离线 Piper 和 Supertonic 模型；Linux x64 还可通过可选运行时使用 SILMA。

系统要求是什么？

Android: arm64-v8a 设备上的 Android 8.0 / API 26 及以上版本。

iOS: 已在计划中，即将登陆 App Store。

macOS: Apple Silicon 或 Intel Mac 上的 macOS 10.13 及以上版本。

Linux: 已安装 WebKitGTK 和 GStreamer 的 amd64 Linux；发布文件在 Ubuntu 24.04 上构建。

Windows: 安装 Microsoft Edge WebView2 运行时的 Windows 10 及以上 x64 系统。

Android

请在浏览器或文件管理器的设置中启用安装未知应用，然后打开 APK。阅读和搜索可离线使用。只有当您选择下载语音模型时才会访问网络；如果不使用有声读物生成功能，则无需网络连接。

Linux

需要已安装 WebKitGTK 和 GStreamer 的 amd64 Linux。发布文件在 Ubuntu 24.04 上构建。

基于 Debian 的发行版（Ubuntu、Mint）： sudo apt install ./Papercut_*.deb

基于 RPM 的发行版（Fedora、openSUSE）： sudo rpm -i Papercut-*.rpm

AppImage： 添加可执行权限（chmod +x）后直接运行。在基于 Arch 的系统上，AppImage 可能需要设置 WEBKIT_DISABLE_COMPOSITING_MODE=1；详情请参阅 README。

macOS

需要运行 macOS 10.13 及以上版本的 Apple Silicon 或 Intel Mac。打开 .dmg，然后将 Papercut 拖入“应用程序”文件夹。正式发布版本已使用 Developer ID 签名并经过公证。如果您正在测试未签名的 CI 或本地开发版本，请在首次启动时右键单击（或按住 Control 单击）应用图标，然后选择打开。

请选择与 Mac 匹配的版本：Apple Silicon（_aarch64.dmg）适用于 M 系列芯片；Intel（_x64.dmg）适用于 Intel Mac。

Windows

需要 x64 硬件上的 Windows 10 及以上版本和 Microsoft Edge WebView2 运行时。MSI 安装包会自动完成设置。如果您更喜欢便携式 EXE，可直接运行，无需管理员权限。

在哪里可以找到文档、发布版本和源代码？

有关设置帮助和平台详情，请先查看 README。您还可以在发布说明中了解新功能，浏览所有发布版本，或在 GitHub 上参与贡献。
