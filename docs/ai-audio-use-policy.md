# AI Audio Use Notice

Last updated: 2026-07-13

Papercut can generate synthetic speech from text. This note is product guidance,
not legal advice.

## User Notice

Use this copy anywhere Papercut needs a short disclosure before audio leaves the
app:

> This export contains synthetic speech generated by Papercut. If you share,
> publish, sell, or broadcast it, label it as AI-generated and do not use it to
> impersonate or mislead.

For reference-voice models such as SILMA, add:

> This voice uses a reference recording, so only export it if you have
> permission to use that voice and recording.

## UI Placement

Keep the notice contextual:

- saved audiobook cards identify generated audio;
- export menus remind users to label shared audio;
- export confirmation repeats the disclosure before the file picker opens.

Do not use an app-start modal for this. The export flow is the point where the
user can still make an informed choice without adding noise to normal reading or
local playback.

## Canadian Risk Notes

For Canadian distribution, keep these policy lines clear:

- Papercut should accurately state whether documents, audio, and models stay
  local or are uploaded.
- Users should not use generated audio for impersonation, fraud, fake
  endorsements, harassment, or deceptive commercial claims.
- Users are responsible for rights in source text, reference recordings,
  performances, and voices.

Before public release, have Canadian counsel review the final Privacy Policy,
Terms/Acceptable Use text, and in-app export notice.

## Reference Voice Shipping

Do not ship a default reference voice unless the recording is owned by Papercut
or explicitly licensed for redistribution, commercial use, TTS reference use,
generated-audio output, and app-user access. A permissive model or code license
does not automatically clear rights in the reference recording, the speaker's
performance, or the speaker's identity.

For SILMA, keep the upstream sample voice as development-only until upstream
confirms the reference WAV can be redistributed and exposed as a default voice
profile in Papercut.
