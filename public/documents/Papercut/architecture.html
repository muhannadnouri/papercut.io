How Papercut Works

Papercut is built around a simple local workflow: import documents, search across them, read what matters, and save audio when listening is more useful than reading.

Local library

Imported HTML and EPUB files are converted into app-owned reading documents and stored on your device. You can organize imported documents into folders, move them later, or remove them from local storage.

Search

Papercut combines local search over bundled documents with local search over your imported documents. Exact quoted phrases are checked against document text so you can find specific passages, not just loose keyword matches.

Reader

The reader opens stored HTML content inside the app instead of relying on a browser tab. EPUB imports are turned into a generated reading document so books can share the same reading, search, and audio workflow.

Audiobooks

Audio generation runs on-device when the required voice model is installed. Saved audiobooks can be played later, exported as Papercut audiobook bundles, and imported again on another device.

Privacy model

Documents, search, reading, and generated audio are local-first. Papercut does not need accounts, subscriptions, API keys, or cloud processing for its core workflow.

Technical notes

  • The app interface is built with React and TypeScript.
  • Desktop and mobile packaging is handled through Tauri.
  • Bundled starter documents use Pagefind for local indexing.
  • Imported documents are stored and searched locally by the app.
