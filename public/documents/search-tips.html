Search Tips and Techniques

Use Search when you remember a phrase, a term, or only the rough idea of where something appeared. Papercut searches bundled starter documents and the HTML or EPUB files you import.

Run a search

Type your query in the Search tab, then submit it. Results show matching documents with excerpts. Opening a result takes you to the likely match and highlights it when Papercut can line the snippet up with the rendered document text.

Search exact phrases

Use quotation marks when word order matters. For example, searching for "offline audiobook" keeps results focused on documents that contain that exact phrase instead of matching the words separately.

Narrow the scope

Use the document scope controls to search only selected documents or groups. This is useful when your library grows and you want to focus on one folder, author, manual, or research set.

When results look broad

  • Add a second or third specific term.
  • Use quotes for exact wording from a book, note, or manual.
  • Open a result to jump to the likely match, then use the in-document find control to move through other matches in that document.

Offline search

Search runs locally. Bundled documents use a compact local index, while imported documents are searched from local app storage.
